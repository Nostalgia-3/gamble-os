Page #1 (0x00000000 - 0x00001000)
    This page will never point to real address space, so page faults happen
    when trying to access NULL

kernel virtual memory map:
    0x00000000 - 0x00000FFF : Always maps to an invalid page
    0x00001000 - 0xBFFFFFFF : Process memory
    0xC0000000 - 0xFFFFFFFF : Kernel memory (don't touch)
